# Leadcore Trolling Calculator

Counter-based leadcore line-out calculator with per-lure curves learned from your own depth readings. See `SPEC.md`.

```
npm install
npm run dev      # local dev server
npm test         # engine + data tests
npm run build    # production build in dist/
```

Deploys to GitHub Pages on push to `main` (enable Pages with source "GitHub Actions" in repo settings).
